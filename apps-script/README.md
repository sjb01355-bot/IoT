# 오아시스 Apps Script 웹앱

Google 스프레드시트에 참여자와 모니터링 일지를 저장합니다. 웹앱에서 참여자 검색, 설치 상태 변경, 일지 작성, 사진 첨부, 기기 수량 집계를 할 수 있습니다.

## 처음 설치

1. 운영자 Google 계정에서 빈 스프레드시트를 만든 뒤 **확장 프로그램 → Apps Script**를 엽니다.
2. 이 폴더의 `Code.gs`를 복사합니다. 편집기의 **+ → HTML**에서 `Index`, `Styles`, `Workbook`, `Client` 파일을 만든 뒤 각 파일 내용을 붙여넣습니다.
3. **프로젝트 설정 → 편집기에 appsscript.json 매니페스트 파일 표시**를 켜고 이 폴더의 매니페스트로 바꿉니다. 매니페스트가 엑셀 변환에 필요한 **Drive API v3** 고급 서비스를 등록합니다. 프로젝트가 표준 Google Cloud 프로젝트에 연결되어 있다면 해당 프로젝트에서도 Drive API를 활성화합니다.
4. 편집기에서 `setupOasis` 함수를 실행하고 Google 권한을 승인합니다. 원본 스프레드시트에 **참여자 기록**, **모니터링 기록** 탭이 생성됩니다.
5. **배포 → 새 배포 → 웹 앱**에서 실행 계정을 **나**, 액세스 권한을 **나만**으로 선택해 배포합니다. 운영자 Google 계정으로 배포 화면의 `/exec` URL을 엽니다.

## 사용

- 첫 화면의 가상 예시는 스프레드시트에 저장되지 않습니다. **엑셀 가져오기**에서 최대 6MB의 오아시스 설치명단 `.xlsx`를 선택하면 실제 업무를 시작할 수 있습니다. 가져오기 과정에서 생성되는 임시 변환 파일은 처리 후 제거됩니다.
- 수량이 있는 행의 초기 설치 상태는 **설치 완료**이며 참여자 상세에서 바꿀 수 있습니다. 같은 양식을 다시 가져오면 엑셀 번호로 참여자를 찾아 갱신하고 일지는 유지합니다. 같은 번호에 다른 이름이 있으면 전체 가져오기를 중단합니다.
- 일지는 첨부 일지의 항목을 기준으로 웹 화면에서 작성합니다. 사진은 왼쪽과 오른쪽에 한 장씩 최대 두 장을 첨부할 수 있으며, JPG, PNG, WebP 형식으로 장당 최대 3MB입니다.
- 저장한 일지를 열고 **다운로드**를 누르면 기본 정보, 기기별 점검 표시, 상담 내용, 슈퍼비전, 사진을 담은 Excel 문서(.xlsx)를 받습니다. 사진은 두 칸에 나란히 배치되며 A4 세로 인쇄 설정이 적용됩니다.
- 기록 탭은 앱이 관리합니다. 참여자와 일지는 웹앱에서 수정하세요. 연락처·주소·사진은 원본 스프레드시트에 저장되므로 스프레드시트 공유 권한도 운영자에게만 부여합니다.

## 앱 업데이트

파일을 바꾼 뒤 **배포 → 배포 관리 → 수정 → 새 버전**으로 기존 배포를 갱신하면 같은 URL을 사용합니다.
